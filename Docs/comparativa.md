# Actividad Comparativa: Python vs Java Moderno (21+)

Este proyecto analiza y compara la sintaxis y los conceptos fundamentales entre **Python** y **Java Moderno (Java 21+)**.

## Estructura del proyecto

- `python/`: Scripts de Python demostrando definición de funciones y lectura de entrada de usuario (`input()`).
- `java/`: Código equivalente en Java Moderno aprovechando las *Top-Level Statements*, inferencia de tipos (`var`) y `Scanner`.

## Conceptos comparados

| Concepto | Sintaxis en Python | Sintaxis en Java Moderno |
| :--- | :--- | :--- |
| **Definición de función** | `def doblar(numero):` | `double doblar(double numero) {` |
| **Delimitación** | Indentación (espacios) | Llaves `{` ... `}` |
| **Lectura de datos** | `input()` | `Scanner` |
| **Salida en consola** | `print()` | `System.out.println()` |
